# 3D狙击手掩护行动 — 设计文档

## 1. 概述

**目标**：将现有2D横版狙击游戏重构为第一人称3D狙击游戏（FPS风格），使用Three.js WebGL渲染引擎。

**核心体验**：玩家固定在制高点狙击位，通过3D瞄准镜观察纵深战场，狙杀各距离上的敌人，掩护队友穿越战场。

**技术路线**：Three.js ES modules + importmap CDN，不依赖构建工具，直接在浏览器中运行。

[来源: Three.js FPS Game Starter — shanebrumback.com](https://www.shanebrumback.com/tutorials/first-person-shooter-game-starter.html)

## 3. 技术架构

### 3.1 整体架构

```
┌─────────────────────────────────────────────────┐
│  index.html  (importmap → Three.js CDN)         │
├─────────────────────────────────────────────────┤
│  js/main.js        — 游戏循环、状态管理、场景初始化 │
│  js/scene-setup.js — Three.js 场景/渲染器/光照    │
│  js/camera-controls.js — FPS相机、PointerLock、Scope│
│  js/terrain.js     — 3D地形生成                   │
│  js/characters.js  — 低多边形人物工厂              │
│  js/enemies.js     — 敌人AI                       │
│  js/allies.js      — 队友推进                     │
│  js/weapon.js      — 狙击枪、瞄准镜、弹道           │
│  js/levels.js      — 关卡数据(3D坐标)              │
│  js/input.js       — 输入管理                     │
│  js/audio.js       — 音效系统(复用)                │
│  js/particles.js   — 3D粒子特效                   │
│  js/hud.js         — HUD和菜单系统                 │
└─────────────────────────────────────────────────┘
```

### 3.2 坐标系约定

- **Y轴向上**，与Three.js默认一致
- 玩家狙击位在 `(0, 5, 0)` — 高处，俯瞰战场
- 战场从 `Z = -10` 到 `Z = -60`（纵深方向）
- 战场宽度从 `X = -30` 到 `X = 30`
- 队友从 `X = -20, Z = -20` 向 `X = 20, Z = -20` 推进
- 敌人分布在战场各位置

### 3.3 场景布局

```
        玩家视角 (0, 5, 0)
              │
              │ 俯瞰
              ▼
   ┌──────────────────────────┐  Z = -10
   │  掩体   掩体    掩体      │
   │  敌人A  敌人B   敌人C     │
   │   ██     ██     ██       │
   │  队友→→→→→→→→→→→→→      │  Z = -25 (路径)
   │   ██     ██     ██       │
   │  敌人D  敌人E   敌人F     │
   │  掩体   掩体    掩体      │
   │          Boss             │  Z = -50
   └──────────────────────────┘  Z = -60
```

### 3.4 人物设计（低多边形）

每个角色由基本几何体组合（BoxGeometry / SphereGeometry / CylinderGeometry）：

```
       ●  ── SphereGeometry (头)
      /|\ ── BoxGeometry (躯干) + CylinderGeometry (手臂)
       / \ ── CylinderGeometry (腿)
```

- 队友：绿色系配色，尺寸稍小
- 敌人：红色系配色，不同兵种尺寸不同
- Boss：大型机甲，Box组合 + 发光核心

## 4. 核心模块设计

### 4.1 scene-setup.js
- 创建 Three.js Scene、PerspectiveCamera、WebGLRenderer
- 添加环境光（AmbientLight）+ 定向光（DirectionalLight）
- 开启阴影
- 添加背景色（天空渐变）

### 4.2 camera-controls.js
- 使用 PointerLockControls 实现鼠标视角控制
- 限制俯仰角（-30° ~ 30°），模拟狙击手不能完全朝下
- 固定位置 `(0, 5, 0)`，不可移动
- Scope模式：增加相机焦距（zoom），缩小FOV
- 鼠标灵敏度可调

### 4.3 terrain.js
- 地面：大平面，绿色/棕色材质
- 道路：灰色长条，从Z=-20延伸到Z=-35
- 建筑/掩体：BoxGeometry 组合，随机分布
- 远景：山丘轮廓（用ConeGeometry/BoxGeometry）
- 不同地形风格：草原、雪原、沙漠、废墟、基地

### 4.4 characters.js
- 工厂函数 `createCharacter(type, color)` 返回 Group
- 复用几何体，不同材质颜色
- 支持动画帧：站立/走路/死亡（通过旋转/位移模拟）
- 支持血条显示（Sprite）
- 支持受击闪烁（材质颜色变化）

### 4.5 enemies.js
- 继承现有敌人AI逻辑，适配3D坐标
- 静止兵：固定位置
- 巡逻兵：X轴来回移动
- 冲锋兵：向队友Z轴方向冲
- 掩体兵：周期性显隐
- 狙击手：瞄准后射击
- Boss：大型机甲，多阶段

### 4.6 weapon.js
- 狙击枪模型：CylinderGeometry + BoxGeometry 组合
- 射击：Raycaster 从相机中心发射，检测敌人
- 开镜：TWEEN 动画过渡，FOV从75→15
- 弹道线：Line 可视化子弹轨迹
- 后坐力：相机轻微抖动
- 弹药管理

### 4.7 levels.js
- 8关3D坐标重新设计
- 每关定义：地形、敌人位置、掩体、队友路径、Boss
- 使用3D坐标 `{x, z}` 代替2D的 `x`

### 4.8 audio.js
- 复用现有 `js/audio.js` 的 WebAudio 合成系统
- 适配新射击/命中/击杀事件

### 4.9 particles.js
- 3D粒子系统：使用 Three.js Points / Sprite
- 命中火花：金色粒子散射
- 击杀爆炸：碎块飞散 + 烟雾
- 枪口烟：灰色粒子团

## 5. 游戏状态机

```
MENU → SELECT → PLAYING → (WIN / DEAD) → SELECT / RETRY
                      ↕
                    PAUSED
```

- MENU: 主菜单，显示游戏标题和开始按钮
- SELECT: 选关界面，显示已解锁关卡
- PLAYING: 游戏中，3D场景渲染
- WIN: 通关结算，显示星级评分
- DEAD: 失败，显示重试按钮
- PAUSED: 按P暂停
