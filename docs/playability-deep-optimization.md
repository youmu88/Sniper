# 可玩性与趣味性深度优化 · 设计文档

## 背景与目标
对现有 3D 狙击游戏做深度可玩性升级，聚焦 4 个明确问题 + 举一反三：
1. 敌人移动仍偏快；普通巡逻应更慢，受伤后应加速（激怒机制）。
2. 场景单一，布景匮乏。
3. 敌人形象/障碍物粗糙，需更精细精美。
4. 狙击镜不够高清逼真（精密刻度、距离、红外热点透视）。

## 方案总览

### A. 敌人速度与激怒机制（enemies.js + levels.js 语义保留）
- 全局速度调谐：`patrol` 显式速度 ×0.75、`charger` ×0.8（构造时应用，levels 数据不改动语义，实际更慢）。
- 新增**激怒（enraged）**机制：敌人受击且未死 → 进入狂暴态：
  - patrol 激怒：不再巡逻折返，直线冲向队友（速度 ×1.7），贴脸自爆（复用 charger 判定）——必须优先处理！
  - charger 激怒：速度 ×1.6。
  - stationary/crouch/sniper/heavy 激怒：射速 ×1.4（原地反击更凶）。
  - 激怒外观：emissive 偏橙更亮（与红外机制叠加，`_applyThermal` 内读取 `this.enraged`）。
- Boss 走既有 phase 机制，不叠加激怒。

### B. 场景布景丰富（terrain.js 新增 createProps）
按地形主题差异化布景（15~25 个 props/关，置于战场两侧与纵深，避开道路与敌群）：
- 草原：树丛、灌木、岩石、沙袋堆、铁丝网
- 城镇：墙体、电线杆、木箱堆、路障
- 城镇夜：发光路灯（emissive 假光源，无真实点光源保性能）、断墙、箱堆
- 沙漠：仙人掌、风化岩石、石柱
- 废墟：瓦砾堆、断墙、烧毁车辆残骸
- 雪原：松树、雪堆、岩石
- 机甲基地：金属立柱、警示灯（emissive）、金属箱
- 公共：沙袋堆（交错 box）、铁丝网（线框）、木箱堆
- 木箱升级为 CanvasTexture 板条纹理，摆脱裸 box。

### C. 敌人形象与障碍物精细化（characters.js + enemies.js）
- `createCharacter(colorKey, scale, variant)` 新增兵种变体：
  - sniper：深色兜帽/披风剪影
  - heavy：宽肩甲 + 更宽头盔
  - charger：红色头带 + 臂刀
  - crouch：整体压低（scale.y×0.7）蹲姿
- enemies.js 构造按 `this.kind` 传 variant（boss 保持机甲）。
- 障碍物：沙袋堆、铁丝网、板条木箱、瓦砾/断墙/车辆残骸。

### D. 狙击镜高清化（index.html + main.js + enemies.js）
- 精密刻度：8 根密位线（0/45/90/135°）+ 中心红点 + 细十字 + 玻璃高光渐变 + 红外暗角。
- 动态距离读数：`#scope-range` 每帧显示最近敌人距离（如 "▲ 128m"）。
- 红外热点透视：每个敌人带 3D 距离标签 sprite（镜内显示 "▲ 128m"），仅开镜可见，由 main.js 驱动。
- **hitmarker 击杀标记**：命中白 X 弹跳、击杀红 X（CSS 动画，hud.js 提供方法）。
- **受击红闪**：队友掉血时屏幕边缘红晕（hud.js 提供方法）。

### E. 举一反三
- 敌人激怒时 HUD 提示「⚠ 敌人狂暴」一次。
- 射速/后坐力/呼吸晃动保持既有手感，不动弹道与胜负/存档链路（避免回归）。

## 简化度
新增内容均为独立模块函数（createProps / 兵种 variant / hitmarker / 距离标签），逻辑集中、无分支爆炸；不触碰已封板的胜负判定、存档、队友推进纯函数。
