# 狙击手掩护行动 — 游戏设计文档

## 1. 游戏概述

**游戏名**：狙击手掩护行动（Sniper Cover Duty）

**类型**：2D 横版狙击战术游戏（HTML5 Canvas）

**核心玩法**：玩家扮演隐蔽在制高点的狙击手，通过瞄准镜观察战场、狙杀敌方威胁，掩护卡通形象的队友从起点推进到终点完成任务。难度随关卡循序渐进，最终面对 Boss 战。

## 2. 核心循环

1. 关卡开始，队友从左侧出发向右推进
2. 敌方从掩体后 / 持续推进点出现，向队友开火
3. 玩家用鼠标瞄准镜定位目标区域，点击开火狙杀
4. 队友在掩护下前进，抵达集结点完成任务
5. 队友血量扣完则失败重试

## 3. 三个关键元素

| 元素 | 实现 | 细节 |
|------|------|------|
| **玩家（狙击手）** | 隐蔽在画面顶部/后方掩体，不移动，只有瞄准镜 | 十字线跟随鼠标，右键/空格开镜放大，左键射击；有倒地/瞄准手感 |
| **队友** | 卡通像素战士，自动沿路径推进 | 有 HP，被敌方火力命中会扣血；推进到终点胜利 |
| **敌方** | 卡通像素敌军，从掩体/刷新点出现 | 射击队友，需被击杀；不同敌人有不同血量和射击频率 |

## 4. 关卡设计（8关）

| 关卡 | 名称 | 难度 | 敌方配置 | 特征 |
|------|------|------|----------|------|
| L1 | 初出茅庐 | ★ | 静止靶 3 | 教学关，仅固定靶 |
| L2 | 稳步推进 | ★★ | 静止靶+1移动兵 | 引入移动敌人 |
| L3 | 火力集结 | ★★☆ | 多静止靶+2移动兵 | 火力密度增加 |
| L4 | 夜色迷踪 | ★★★ | 掩体后敌人+移动 | 敌人藏掩体，需等探头 |
| L5 | 敌后穿插 | ★★★☆ | 混合+会冲锋的近战兵 | 引入冲锋兵（快速逼近队友） |
| L6 | 火力压制 | ★★★★ | 大量混合敌人 | 高强度火力，需优先清高威胁 |
| L7 | 铁血长廊 | ★★★★☆ | 精英敌人+狙击手 | 敌方狙击手反制（会反击玩家） |
| L8 | 终极Boss | ★★★★★ | Boss+守卫 | 巨型机甲Boss，多阶段 |

**难度递进维度**：敌人数量↑、移动速度↑、射击频率↑、掩体掩护↑、出现规则复杂化。

## 5. 技术架构

```
index.html          — 页面骨架
css/style.css       — UI 样式
js/sprites.js       — 像素风卡通形象生成（程序化 Canvas 绘制）
js/levels.js        — 8 关数据定义
js/input.js         — 鼠标/键盘输入管理
js/enemies.js       — 敌人 AI（移动、射击、掩体）
js/allies.js        — 队友推进逻辑 + HP
js/game.js          — 核心游戏引擎（状态机、碰撞、射击、弹道）
js/main.js          — 入口、菜单、HUD、主循环
```

- 采用模块化 + 全局命名空间（`window.Sniper`），避免构建工具，可直接打开运行。
- 像素风通过离屏 Canvas 绘制小尺寸图形并放大（imageSmoothingEnabled=false）实现。

## 6. 游戏状态机

- MENU → 选关 → PLAYING → (VICTORY / DEFEAT) → 下一关/重试
- 暂停（P）

## 7. 胜利/失败判定

- **胜利**：队友 HP>0 且到达终点区域
- **失败**：队友 HP ≤ 0

## 8. 交付清单

- 完整可玩的 8 关（含 Boss 战）
- 程序化像素卡通形象（队友、多种敌人、Boss、战场掩体）
- 瞄准镜/开镜/后坐力手感
- 实时 HUD（关卡、敌方存活、队友血条、弹药）
- 菜单、选关、胜负结算、重试

## 10. 实现补充说明

- **敌人兵种**：静止兵、巡逻兵、冲锋兵、掩体探头兵(crouch)、重甲兵(heavy)、敌方狙击手、终极Boss机甲
- **掩体系统**：各关配置沙袋掩体，配合 crouch 探头兵与 L7 狙击手增强战术性
- **弹药系统**：弹药随时间自动回填，开镜(Shift/右键)精确瞄准产生弱点伤害倍率
- **通关流程**：非Boss关队友抵达终点即胜；Boss关需击败Boss且队友抵达终点
- **存档**：localStorage 保存已解锁关卡与星级
